The error itself is vague. To get more details, run:

#+begin_src bash
sudo nixos-rebuild switch --show-trace 2>&1 | tail -50
#+end_src

Or check the journal for the failed unit:

#+begin_src bash
journalctl -u sops-nix.service -n 50
#+end_src

Since you changed the key location, the likely issue is that the new key file doesn't exist yet at the path specified in =age.keyFile=. Check:

#+begin_src bash
ls -la /var/lib/sops-nix/key.txt
#+end_src

If it's missing, you need to copy your age key there:

#+begin_src bash
sudo mkdir -p /var/lib/sops-nix
sudo cp /home/lyterk/.config/sops/age/keys.txt /var/lib/sops-nix/key.txt
sudo chmod 600 /var/lib/sops-nix/key.txt
#+end_src

Then retry the rebuild.
