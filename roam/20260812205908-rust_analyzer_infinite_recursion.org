** What's Happening

The error is caused by a *circular fallback loop*:

1. =rustup= (or some toolchain manager) looks for =rust-analyzer= for the active toolchain
2. It can't find it, so it "falls back" to =/home/lyterk/.nix-profile/bin/rust-analyzer=
3. But that binary *is* =rustup='s shim (or a wrapper that calls back into rustup)
4. Which again can't find rust-analyzer → falls back → infinite recursion

** Root Cause

Your =/home/lyterk/.nix-profile/bin/rust-analyzer= is likely a *rustup shim*, not the actual =rust-analyzer= binary. When rustup can't find rust-analyzer for your active toolchain, it calls the fallback, which is itself.

** Fixes

*Option 1: Install rust-analyzer via rustup*
#+begin_src bash
rustup component add rust-analyzer
#+end_src

*Option 2: Install the real binary via Nix*
#+begin_src nix
# configuration.nix or home-manager
environment.systemPackages = [ pkgs.rust-analyzer ];
#+end_src

*Option 3: Check what the binary actually is*
#+begin_src bash
cat /home/lyterk/.nix-profile/bin/rust-analyzer
# or
file /home/lyterk/.nix-profile/bin/rust-analyzer
#+end_src

If it's a shell script wrapping rustup, that confirms the loop.

** Likely Best Fix

Since you're on NixOS, the cleanest solution is having *both* present: rust-analyzer from nixpkgs /and/ =rustup component add rust-analyzer= so the toolchain-specific lookup succeeds without falling back.
