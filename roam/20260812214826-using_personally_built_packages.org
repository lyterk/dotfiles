*The problem:* In =configuration.nix=, you have:

{ config, pkgs, lib, pkgs-unstable, bell, ... }:

But =bell= isn't passed as a =specialArgs= — it comes through the module system. The =resourcesDir= line:

#+begin_src nix
resourcesDir = "${bell.packages.x86_64-linux.default}/resources";
#+end_src

...won't work because =bell= (the flake) isn't in scope in a module file.

*Fix — use the package that's already built into the flake output:*

#+begin_src nix
services.bell = {
  enable = true;
  resourcesDir = "${pkgs.bell}/resources";  # if overlaid, or:
};
#+end_src

Or more simply, since your =postInstall= copies resources into the package output, just reference it via the NixOS module's own package. The cleanest fix is to add a =package= option to your bell module:

In =bell/flake.nix=, add to the module options:
#+begin_src nix
package = lib.mkOption {
  type = lib.types.package;
  default = self.packages.${pkgs.system}.default;
};
#+end_src

Then in =serviceConfig=:
#+begin_src nix
ExecStart = "${config.services.bell.package}/bin/bell";
WorkingDirectory = config.services.bell.resourcesDir;
#+end_src

And in =configuration.nix=, remove =bell= from the function args (it's not passed there) and use:
#+begin_src nix
services.bell = {
  enable = true;
  resourcesDir = "/run/current-system/sw/share/bell/resources"; # or hardcode path
};
#+end_src

*Simplest working approach* — just hardcode the resources path to what =postInstall= puts in the store, by making the module default to the bundled resources:

#+begin_src nix
# In the module, make resourcesDir optional with a sensible default:
resourcesDir = lib.mkOption {
  type = lib.types.str;
  default = "${self.packages.${pkgs.system}.default}/share/bell/resources";
  description = "Path to directory containing audio files";
};
#+end_src

Then =configuration.nix= just needs:
#+begin_src nix
services.bell.enable = true;
#+end_src

And remove =bell= from the function argument list in =configuration.nix=.

The error says =services.bell.resourcesDir= has no value defined, meaning the default isn't being evaluated properly.

The issue is in your =bell/flake.nix= module — the =default= for =resourcesDir= references =self.packages.${pkgs.system}.default=, but =pkgs.system= may not be available in the module context when evaluated from an external flake.

Fix in =bell/flake.nix=:

#+begin_src nix
resourcesDir = lib.mkOption {
  type = lib.types.str;
  default = "${self.packages.${pkgs.stdenv.hostPlatform.system}.default}/share/bell/resources";
  description = "Path to directory containing audio files";
};
#+end_src

Note =pkgs.stdenv.hostPlatform.system= instead of =pkgs.system= — which also matches the deprecation warning you're seeing: ='system' has been renamed to/replaced by 'stdenv.hostPlatform.system'=.

Push that change to GitHub, then update your flake lock:

#+begin_src bash
sudo nix flake update bell --flake /etc/nixos
sudo nixos-rebuild switch --flake /etc/nixos#miranda
#+end_src
