Here are the major things in =desktop/configuration.nix= that differ from the laptop setup and are worth preserving:

1. *Boot loader*: Desktop uses GRUB with LUKS encryption (=luks-*= devices, =crypto_keyfile.bin=), vs laptop's =systemd-boot=.

2. *Git server*: A =git= system user with =git-shell=, SSH authorized keys, and =/var/lib/git-server= home — entirely absent from laptop.

3. *Immich*: Photo management server with =mediaLocation = "/mnt/orange/immich"=.

4. *Nginx*: Reverse proxy in front of Immich with large upload size config.

5. *Plex*: Media server with =openFirewall = true=.

6. *OpenSSH*: Enabled on port =65222= with hardened settings (=PasswordAuthentication = false=, no root login, allowlist of users including =git=).

7. *=home-manager.backupFileExtension=*: Set to ="backup"= — useful to carry over.

8. *=programs.light.enable=*: Backlight control (may not apply to desktop but worth noting).

9. *=services.gnome.gnome-keyring=*: Enabled at system level (laptop has it in home-manager).

10. *Dvorak console keymap*: Desktop uses =console.keyMap = "dvorak"= vs laptop's ="us"=.

11. *Desktop-specific packages*: =plex=, =beancount-language-server=, =immich=, =cargo=, =clojure=, =poetry=, =elixir= — some may now live in =home-base.nix= but worth auditing.
