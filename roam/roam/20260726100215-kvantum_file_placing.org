The error is:
#+begin_src 
mkdir: cannot create directory '/home/lyterk/.config/Kvantum/Base16Kvantum': File exists
ln: failed to create symbolic link '...Base16Kvantum.kvconfig': No such file or directory
#+end_src

The =mkdir= succeeds in finding the directory exists, but then =ln= can't create the symlink — this means =/home/lyterk/.config/Kvantum/Base16Kvantum= exists but is a *file* (or broken symlink), not a directory.

Try:
#+begin_src bash
ls -la ~/.config/Kvantum/
rm -rf ~/.config/Kvantum/Base16Kvantum
#+end_src

Then rebuild. The directory might be a leftover file/broken symlink from a previous generation that's confusing home-manager's link generation.

Also, search your nix config for what's generating this — it's likely a theming module:
#+begin_src bash
grep -r -i "kvantum\|base16\|stylix\|nix-colors" /etc/nixos/
#+end_src

If you're using *Stylix* or *base16*, those often configure Kvantum automatically even if you don't explicitly reference it.
