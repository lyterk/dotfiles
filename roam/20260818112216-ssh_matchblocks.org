The issue is that the ="*"= wildcard host entry is being interpreted differently. The =Host= attribute in home-manager's SSH module expects a specific structure. The wildcard ="*"= with nested attributes is likely causing the coercion error.

The correct structure uses =matchBlocks= instead of =Host=:

#+begin_src diff
-    ssh = {
-      enable = true;
-
-      settings = {
-        Host = {
-          "*" = {
-            User = "git";
-            Port = 22;
-          };
-          "git" = {
-            HostName = "txru.me";
-            Port = 65222;
-            User = "git";
-            IdentityFile = "~/.ssh/id_ed25519";
-          };
-          "github" = {
-            HostName = "github.com";
-            User = "git";
-            IdentityFile = "~/.ssh/id_ed25519";
-          };
-          "bitbucket" = {
-            HostName = "bitbucket.org";
-            User = "git";
-            IdentityFile = "~/.ssh/id_ed25519";
-          };
