Here are some good file picker options for NixOS + Sway:

** GTK-based (integrates with portal)
- *Nautilus* - GNOME Files, works as a portal backend, image thumbnails
- *Thunar* - XFCE's file manager, lightweight, good keyboard nav

** Native Wayland / Keyboard-focused
- *lf* + *sixel/kitty* - terminal but excellent keyboard nav, image preview in kitty
- *yazi* - modern terminal file manager, excellent image preview (sixel/kitty protocol)
- *nnn* - fast terminal file manager with image preview plugin

** Dedicated Pickers (no full terminal needed)
- *fuzzel* - not a file picker but launcher-style
- *wofi* + scripts - can be wired up for file picking
- *xdg-desktop-portal-gtk* - provides native GTK file chooser dialog (most apps use this)

** Best practical options for Sway:
1. *=xdg-desktop-portal-gtk=* - Already handles most app file dialogs transparently with image thumbnails. Make sure it's enabled.
2. *Thunar* - Good balance of keyboard use + images, light dependencies
3. *Yazi* - If you're okay with a terminal popup, best image preview support

Check if you have =xdg-desktop-portal-wlr= or =xdg-desktop-portal-gtk= configured, as that covers most use cases without a dedicated file manager.

To use Yazi as your file picker in Sway/NixOS, you have a few options depending on what's invoking the file picker:

** For XDG Desktop Portal (GTK apps, Firefox, etc.)

The GTK file chooser dialog comes from =xdg-desktop-portal=. You can replace it with a terminal-based picker using *=xdg-desktop-portal-termfilechooser=*:

#+begin_src nix
# In your NixOS or home-manager config
xdg.portal = {
  enable = true;
  extraPortals = [ pkgs.xdg-desktop-portal-termfilechooser ];
  config.common.default = "*";
  config.sway = {
    "org.freedesktop.impl.portal.FileChooser" = "termfilechooser";
  };
};
#+end_src

Then configure it to use Yazi. The portal needs a wrapper script:

#+begin_src nix
# ~/.config/xdg-desktop-portal-termfilechooser/config
[filechooser]
cmd = /path/to/yazi-wrapper.sh
#+end_src

A minimal wrapper script:
#+begin_src bash
#!/usr/bin/env bash
# args: $1=path hint, rest=extra args
foot yazi "$1" # or your preferred terminal
#+end_src

** Caveats

- =xdg-desktop-portal-termfilechooser= has a specific script interface — check the [upstream repo](https://github.com/hunkyburrito/xdg-desktop-portal-termfilechooser) for the exact script API
- Some GTK4 apps bypass the portal entirely
- This affects *open/save dialogs*, not file manager launching

** In NixOS packages

#+begin_src nix
environment.systemPackages = [ pkgs.xdg-desktop-portal-termfilechooser ];
#+end_src

Check if it's in nixpkgs: =nix search nixpkgs xdg-desktop-portal-termfilechooser=.

To use Yazi as a file manager in your setup, you have a few integration points:

** 1. Add yazi to home packages

In =home-base.nix=, add to =fileSystems= (or another group):
#+begin_src nix
fileSystems = with pkgs; [
  calibre
  thunar
  duplicity
  yazi  # add this
];
#+end_src

(Note: =yazi= is already in =configuration.nix= system packages, but better to have it in home packages too.)

** 2. Add a sway keybinding for yazi

In =sway/default.nix=, add to the =kevin= mode and =wkKevin= config:

#+begin_src nix
# In wkKevin menu:
y = {
  desc = "Yazi file manager";
};

# In modes.kevin:
"y" = "exec ${pkgs.alacritty}/bin/alacritty -e ${pkgs.yazi}/bin/yazi; mode default";
#+end_src

** 3. For XDG file chooser (replacing the portal file picker)

For Wayland file chooser dialogs (e.g. from Firefox), you'd use =xdg-desktop-portal-termfilechooser= (already commented out in your config). Uncomment it:

In =configuration.nix=:
#+begin_src nix
# xdg-desktop-portal-termfilechooser
#+end_src
→ uncomment and add configuration:
#+begin_src nix
xdg.portal = {
  extraPortals = [ 
    pkgs.xdg-desktop-portal-wlr
    pkgs.xdg-desktop-portal-termfilechooser
  ];
};
#+end_src

Then configure it to use yazi — create a wrapper script and point the portal at it. See [the termfilechooser docs](https://github.com/hunkyburrito/xdg-desktop-portal-termfilechooser) for the =TERMCMD= config pointing to =alacritty -e yazi=.

The keybinding approach (step 2) is the simplest win; the portal approach (step 3) replaces system-wide file dialogs.

The issue is that =xdg-desktop-portal-termfilechooser= uses its own wrapper script protocol — yazi needs to write the selected file path(s) to a specific file descriptor or temp file that the portal reads back.

The termfilechooser portal actually ships with example wrapper scripts. You shouldn't be calling yazi directly — you need a wrapper that:

1. Receives the output file path as =$1= (where results should be written)
2. Opens yazi
3. Writes the selected path(s) to that file

Check the [termfilechooser examples](https://github.com/hunkyburrito/xdg-desktop-portal-termfilechooser/tree/master/contrib) — there's a =yazi.sh= wrapper. The key pattern is:

#+begin_src bash
#!/bin/sh
output="$1"
alacritty -e yazi --chooser-file="$output" "${@:2}"
#+end_src

The crucial part is =--chooser-file= — yazi has built-in support for file chooser mode where it writes selections to that file instead of opening them.

Update your wrapper script in =configuration.nix=:

#+begin_src nix
yaziFilePicker = pkgs.writeShellScriptBin "yazi-filepicker.sh" ''
  alacritty -e yazi --chooser-file="$1" "''${@:2}"
'';
#+end_src

The =--chooser-file= flag puts yazi in chooser mode where pressing =Enter= writes the path to the specified file rather than opening it.

#+begin_src
