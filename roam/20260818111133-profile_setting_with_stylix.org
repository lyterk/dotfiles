The error indicates that the =default= profile name and your =kevinDefault= profile are conflicting — the system is creating two profiles: one named =default= (the key in the =profiles= attrset) and one named =kevinDefault= (the =name= field), both with =isDefault = true= and =id = 0=.

The fix is to either rename the attrset key to match your profile name, or remove the redundant =name= field:

#+begin_src diff
--- a/default.nix
+++ b/default.nix
@@ -1,7 +1,6 @@
     profiles = {
-      default = {
+      kevinDefault = {
         id = 0;
-        name = "kevinDefault";
         isDefault = true;
#+end_src

The attrset key is used as the profile name by home-manager, so setting =name= separately creates a mismatch. Using =kevinDefault= as the key (which matches what =lyterk-home.nix= references in =profileNames=) should resolve both assertions.
