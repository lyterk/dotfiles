The difference is due to *execute permissions on directories*.

When you run =ls= as a normal user on =/etc/nixos=, you lack *execute (=x=) permission* on the directory. Without =x=, you can't access inode metadata for the contents — so =ls= can see the names (because you have =r= read permission) but shows zeroed-out/missing metadata (size 0, no dates, no real permissions).

When you run =sudo ls=, you have full access and see everything correctly.

The directory permissions =drw-rw-r--= confirm this: *no execute bit* for anyone. So even though =lyterk= owns it and has =rw=, without =x= you can list names but not =stat()= the entries.
