#+begin_src nix
ytsrt = {
  body = ''
    yt-dlp \
      --write-auto-subs \        # Download auto-generated subtitles
      --sub-langs es \           # Only download Spanish subtitles
      --skip-download \          # Don't download the video, only subtitles
      --convert-subs srt \       # Convert subtitles to SRT format
      --extractor-arg "youtube:skip=hls,dash" \  # Skip HLS and DASH formats (faster)
      --ignore-no-formats \      # Don't error if no formats found
  '';
};
#+end_src

Regarding dynamic output filename: Yes, you can use =--output= (or =-o=) with yt-dlp's template syntax:

#+begin_src nix
ytsrt = {
  body = ''
    yt-dlp \
      --write-auto-subs \
      --sub-langs es \
      --skip-download \
      --convert-subs srt \
      --extractor-arg "youtube:skip=hls,dash" \
      --ignore-no-formats \
      --output "$argv[1]" \      # Use first argument as filename
  '';
};
#+end_src

Or using yt-dlp's built-in template variables:
#+begin_src bash
--output "%(title)s.%(ext)s"    # Title of video
--output "%(upload_date)s.%(ext)s"  # Upload date
#+end_src

So you could call it like: =ytsrt "my-filename" <url>=

Note: when using =$argv[1]= as filename, you'd need to pass the URL as =$argv[2]=.
