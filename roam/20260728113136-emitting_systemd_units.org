The issue is that =lib.escapeShellArgs= quotes each list element as a single argument. You need =--exclude= and =node_modules= as *two separate list elements*:

#+begin_src nix
++ [ "--exclude" "node_modules" ]
#+end_src

This way =escapeShellArgs= treats them as two separate arguments rather than one string containing a space.
